# 주요 부품 수명

1 Thermal Grease : 2~5년 (CPU/GPU 온도 80도 이상기준) 2 PCM : 반영구적 3 Heatpipe : 10년~15년 이상 4 Vapor Chamber : 반영구적

최신 제품의 경우는 Thermal Grease 보다 PCM 을 쓰는 추세.  
즉 사용중 Heatpipe 나 V/C 의 사용중 파손이 아니면 문제가 될 여지는 적음

하지만 사용자가 사용중, 뜨거움을 느끼거나 , 셋트가 꺼지는 경우가 발생하면, Thermal 성능을 자가 진단할 수 있는 방법

1. 가장 단순하고 좋은 건, Heatsink 의 T1,T2,TC 에 thermal sensor 를 붙이는 것. 그리고 그걸 읽을 수 있게 하는 것. -> 하지만 지나치게 단순하고 돈이 들어감.
    
2. 두번째는 계산에 의해 몇가지 변인 통제 설정하고 CPU 온도 상승분을 계산  
    ex) FAN 은 Max RPM, GPU/CPU 일정 load 를 가함 계산에 의해 CPU/SNS 온도가 시간동안 일정 온도를 넘으면 안됨 -> 이미 공정 tool 에 적용되어 있으므로 특허라고 하기 어려움
    
3. SMD Gasket 과 Thermal Sensor 등을 활용할 수는 없을까? 하지만 SNS 는 heatsink Pipe Edge 부에 위치하는게 좋은데 통상적으로 보드 위가 아닐 수 있음. --> 이걸 Idea 로 살리는게 좋겠음.
    
4. wire type 의 SNS 가 있나? Heatpipe 의 재료비와 공정상 SNS 에 일체화는 어려움.
    

3번 idea 를 확장하여, heatsink 의 edge 단 bracket 과 Subboard 를 contact 시키는 방법
